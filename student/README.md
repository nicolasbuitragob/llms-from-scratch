# Student Workspace

This is the study workspace for rebuilding ideas from `LLMs-from-scratch` and testing them with `pytest`.

Keep your own implementations here instead of editing the official book code.

Suggested flow:

1. Read the chapter section.
2. Summarize the idea in your own words.
3. Implement a small version yourself.
4. Write focused pytest tests.
5. Run the tests and review failures.

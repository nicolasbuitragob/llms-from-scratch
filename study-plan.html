Method

How every topic runs

  1. RecallFrom memory: questions on past topics. No notes.
  2. ReadOnly the named book section.
  3. ExplainInput, output, and invariant in your words.
  4. AnswerCheckpoint questions without code.
  5. PredictExpected value, shape, and dtype.
  6. TestWrite or enable one focused pytest test.
  7. BuildSmallest code that makes it pass.
  8. CompareOfficial code, only after yours works.

When you are blocked

Give the failing test, the actual result, the expected result, and your explanation. Then climb the ladder one step at a time.

  1. 1Clarify the expected behavior
  2. 2Targeted question from the tutor
  3. 3Next small step
  4. 4Tiny isolated example
  5. 5Full solution — only when you ask

Role split

You

  • Implement
  • Write tests
  • Explain the tensor flow

Tutor

  • Explain concepts
  • Ask checkpoint questions
  • Review code and failures
  • Help design tests

A topic is done when

  • You explain it without the book.
  • It works on small examples.
  • Tests cover core behavior, shapes, and dtypes.
  • Edge cases have intentional behavior.
